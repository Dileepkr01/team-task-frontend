# 🚀 Team Task Manager - Frontend

Frontend for Team Task Manager built with React.

---

## 🌐 Live URL

👉 https://team-task-frontend-gilt.vercel.app/

---

## 📌 Features

* User Signup/Login
* Project management UI
* Task creation & assignment
* Dashboard view
* Role-based UI

---

## 🛠️ Tech Stack

* React (Vite)
* Axios
* React Router

---

## ⚙️ Setup

```bash
npm install
npm run dev
```
